🚀 Publish — Cloudflare & GitHub Pages
Providers grouped together. Simple = download + drag (no token, no Failed to fetch). Advanced = auto API with token.
☁️ Cloudflare
Simple — Pages Direct Upload
1. Choose type below
2. Download
3. dash → Pages → Direct Upload → Drag → *.pages.dev
Advanced — Workers API
Needs Proxy to fix CORS Failed to fetch. Direct api.cloudflare.com blocked.
Where to find Account ID:
1. Go to dash.cloudflare.com
2. Click Workers & Pages in left sidebar
3. Browser URL: dash.cloudflare.com/ACCOUNT_ID/workers
4. Or right sidebar shows Account ID
Example: 44f5bd7d414422d9520c59e89ceb15a7
Live URL will be: https://YOUR-NAME.workers.dev
You must create empty Worker first: Workers & Pages → Create Worker → Name same as here → Deploy empty.
Why Failed to fetch? Browser → api.cloudflare.com blocked by CORS. Proxy fixes it (server-side, no CORS).

Placeholder error you had: https://your-proxy.workers.dev/deploy doesn't exist → fails.

Deploy YOUR proxy (2 min, once):
1. npm i -g wrangler && wrangler login
2. mkdir cf-proxy && cd cf-proxy && wrangler init --no-open (No to git, No to deploy)
3. Replace src/index.js with code from System tab → Cloudflare card
4. wrangler secret put ACCOUNT_ID → paste your Account ID
5. wrangler secret put CF_TOKEN → paste API Token (see permissions below)
6. wrangler deploy → copy real URL like https://cf-deploy-proxy.YOURNAME.workers.dev
7. Paste YOUR real URL here, leave API Token empty.
API Token Permissions (API Tokens, Bearer, not Global Key):
Go to dash.cloudflare.com/profile/api-tokens → Create Token → Use Edit Cloudflare Workers template

✅ Account | Workers Scripts: Edit
✅ Account | Account: Read
✅ Account | Account Settings: Read
✅ Account | Workers: Edit (or Workers Scripts)
✅ Zone | All zones (if template asks)

Token format: starts with long random string. Use as Authorization: Bearer TOKEN.
Note: Direct browser use will still fail with Failed to fetch (CORS). Use Proxy URL instead to hide token.
🐙 GitHub Pages
Simple — Manual Upload
1. Download → rename to index.html
2. github.com/new → repo deckcraft-pro
3. Upload → Settings → Pages → main/root → username.github.io/repo/
Advanced — API with PAT
GitHub API allows direct browser CORS with token, no proxy needed. Auto-creates repo + uploads index.html + enables Pages.
Your GitHub username. Find at github.com → top right avatar → your profile. Repo will be at github.com/OWNER/REPO. Live URL: OWNER.github.io/REPO/
Will create if not exists. Lowercase, no spaces.
GitHub Token Permissions:
Go to github.com/settings/tokens/new
Choose Classic token (not fine-grained for simplicity)

✅ repo — Full control of private repositories
  This allows: create repo, push content, enable Pages

Or fine-grained token:
• Repository access: All repositories or select deckcraft-pro
• Permissions: Contents: Read & Write, Metadata: Read, Pages: Write, Administration: Read & Write

Token format: ghp_xxxxxxxx... or github_pat_...
Scopes needed: repo, workflow (optional)
Note: Unlike Cloudflare Workers API, GitHub API allows direct browser fetch with token (CORS enabled), so no proxy needed. Token is sent as Authorization: Bearer TOKEN.

After deploy: Settings → Pages → Source: main / root should show. Live in 1-2 min at OWNER.github.io/REPO/
Will create repo if needed, upload index.html, enable Pages. Check result box below for live URL.
✅ Simple: Download → Drag to Cloudflare Pages Direct Upload or GitHub Upload → Live, no token, no Failed to fetch.
🔧 Advanced: Cloudflare needs Proxy (placeholder your-proxy... doesn't exist), GitHub needs PAT repo scope.
